\# Daftar Aplikasi Open Source untuk Mahasiswa SI



Berikut beberapa aplikasi Open Source yang bermanfaat untuk mendukung kegiatan akademik mahasiswa Sistem Informasi.



| No. | Aplikasi | Fungsi | Manfaat bagi Mahasiswa SI |

|---|---|---|---|

| 1 | Ubuntu | Sistem operasi Linux | Praktik administrasi sistem dan terminal |

| 2 | LibreOffice | Aplikasi perkantoran | Menyusun laporan dan mengolah data |

| 3 | Mozilla Firefox | Peramban web | Pengujian dan pengembangan aplikasi web |

| 4 | GIMP | Pengolah gambar | Membuat dan mengedit aset visual |

| 5 | VLC Media Player | Pemutar multimedia | Memutar dan menguji berkas multimedia |

| 6 | Git | Sistem pengelolaan versi | Mengelola perubahan kode dan kolaborasi |



\## Kesimpulan



Aplikasi Open Source menyediakan berbagai perangkat yang dapat dimanfaatkan mahasiswa Sistem Informasi untuk belajar, mengembangkan keterampilan teknis, dan berkolaborasi dalam proyek perangkat lunak.
